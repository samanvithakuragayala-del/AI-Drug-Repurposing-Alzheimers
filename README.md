# AI-Based Drug Repurposing for Alzheimer's Disease

## Overview

This project presents a machine-learning-based approach for identifying
potential drug-target interactions that may support drug repurposing research
for Alzheimer's disease.

The system accepts a drug name as input and predicts potential Alzheimer's
disease-associated molecular targets with an interaction probability.

## Key Features

- Drug-name based prediction
- Machine-learning-based drug-target interaction prediction
- Alzheimer's disease target prioritization
- Predicted interaction probability
- Molecular structure visualization
- Top predicted target ranking
- Interactive Streamlit web application
- Research-prioritization disclaimer

## Workflow

## Example Result

Input Drug:

Ramipril

Predicted Target:

SLC6A3

Predicted Interaction Probability:

96.08%

## Model Performance

The developed machine-learning model achieved:

- Accuracy: 70.47%
- Precision: 87.23%
- Recall: 74.31%
- F1-score: 80.25%
- ROC-AUC: 71.03%

## Application

The project includes an interactive web application where users can enter
a drug name and obtain predicted drug-target interactions.

## Research Disclaimer

This application provides in-silico predictions for research prioritization
only. The predictions do not establish therapeutic efficacy, clinical
benefit, or clinical safety.
